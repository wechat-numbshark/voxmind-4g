VoxMind 是一台内置 4G 蜂窝网络的成熟 AI 语音行动终端。实时收音：访谈可马上看文字，也可结束后看完整文字与总结；支持销售拜访自动总结、自定义 AI、飞书任务与记账，并可拓展到控制万物（智能家居/IoT/企业系统）。Plaud 有的核心能力它全有，Plaud 卡片旗舰没有的独立 4G 它已有，且全栈源码公开、小批量发货稳定运行。

内置 ML307C 4G LTE 模组与 Nano-SIM 卡槽，手机不在身边、蓝牙关闭也能持续录音并实时分段上传，断网自动暂存续传。

说完即办 · 确认后执行

不只是录音摘要：AI 识别意图后在机身屏幕或 Web 后台弹出待确认卡片，一键写入飞书任务、消息、云文档、自动记账或联动智能家居。

自带 AI / API · 零订阅绑定

支持接入你自己的大模型与语音识别 API，也支持 Docker 私有化自部署；所有生产密钥与个人设备凭证已彻底剥离，安全可控。

成熟实物 · 全栈源码公开

已完成四层 PCB 打板、3D 外壳 v1/v2 迭代、小批量量产与真实用户交付；硬件制造文件、3D 模型、固件与 Web 控制台同步公开。

对比 Plaud（Note / Note Pro / One）

基于公开规格与真实产品形态的清晰对照：VoxMind 面向「独立 4G 实时行动 + 飞书/企业集成 + 软硬件可定制」。

  • Plaud Note / Note Pro 为卡片式录音硬件，通过蓝牙和 Wi-Fi 经手机 App 同步处理；规格不含独立蜂窝 4G。
  • Plaud Pro Plan 为云端分钟数订阅方案，而非独立硬件；VoxMind 支持自备 AI / API，无需强制按月付费。
  • Plaud One 在耳机充电盒中内置 eSIM 4G LTE，停录后生成摘要与 App Agent；VoxMind 则开放整套硬件、3D 外壳、固件与自托管后台。
