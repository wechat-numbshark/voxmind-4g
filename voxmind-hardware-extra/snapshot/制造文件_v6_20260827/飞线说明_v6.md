## 一、必须焊的飞线（3 根）

| # | 网络 | 起点 | 终点 | 长度 | 必要性 |
|---|---|---|---|---|---|
| 1 | **SIM_N4** | `R16` 内侧焊盘 (57.10, 19.94) 顶层 | 过孔 (68.53, 22.00) | **11.6 mm** | **必须** —— SIM 卡时钟，不接则蜂窝功能失效 |
| 2 | TP_RST | 铜岛 (39.02, 33.89) | 铜岛 (40.39, 27.18) | 6.8 mm | 建议接 —— 触摸屏复位 |
| 3 | EN | 铜岛 (24.69, 18.95) | `J8_5` 焊盘 (35.61, 27.25) 底层 | 13.7 mm | **可不接** —— 只影响调试座的复位支线 |

坐标原点为板左下角，单位 mm。建议用 0.1mm 漆包线，焊后点少量 UV 胶固定。

### 为什么第 3 根可以不接
`EN` 的主块 `U2_3 + R5_1 + C10_1 + SW5_1` 已完整连通 —— MCU 的复位脚有上拉电阻、去耦电容、复位按键 SW5 全都在。
断的只是 J8 调试座那一路。复位可用 **SW5 按键** 或 **USB 原生复位**（ESP32-S3 的 USB-Serial-JTAG 支持 esptool 直接复位进下载模式）。

## 二、为什么这 3 根消不掉（逐条硬判定，非经验判断）

方法：`reach.py` 可达性硬判定 → `wall.py` 找围墙 → `whatif.py` 拆除组合 → 完整 MST 恢复验证净收益。

### SIM_N4 —— 试遍所有方案，全部净收益 ≤ 0

`R16_2` 被困在 **210 格**的自由区里（整板自由空间 125 万格），5mil 线宽也不可达。

| 方案 | 结果 |
|---|---|
| 拆 `SIM_N2` | SIM_N4 通，但 SIM_N2 只恢复 1/3 → **净收益 −1** |
| 拆 `SIM_VDD` | SIM_N4 通，但 SIM_VDD 恢复 4/5 → **净收益 0** |
| 拆 `SIM_CLK` | SIM_N4 通，但 SIM_CLK 恢复 0/1 → **净收益 0** |
| R16 平移（4 个候选位） | 口袋反而从 2864 格缩到 274 格 → 更差 |
| R16 旋转 90° / 270° | 两条网络仍只能通一条（1/2） |

**根因**：R16 这个 0402 电阻的两个脚，在当前几何下**只有一个能逃出去**。
当前板子的选择是保 `SIM_CLK`、断 `SIM_N4`；反过来也一样。

**真正的解**：重排 `R16/R17/R18/R19` 那一簇（四个串阻挤在 x 53.8–61.2 / y 15.3–20.8，被 U2 模组和 SIM 座夹住）。属于 DVT 改板范围。

### TP_RST —— 与 LCD_RST 互锁
拆 `LCD_RST` 后 TP_RST 可布通，但 LCD_RST 恢复 0/1 → 净收益 0。
**两者都是 J5 的网络**，互相卡死。**J5 换 15P 时这一片会完全重排，大概率一并解开。**

### EN —— 与 I2C_SDA 互锁
拆 `I2C_SDA` 后 EN 可布通，但 I2C_SDA 只恢复 1/2 → 净收益 0。

### GPIO0_BOOT —— 已消除 ✅
上一轮判为"不可布"，实为**目标焊盘选错**：选了 `J8_6`，而 `J8_6` 自己困在 5051 格口袋里。
换成同一主块的 `R6_1` 后直接布通（2569mil，4 过孔，余量 1.04），**零代价，不需拆任何线**。

## 四、`pcb check` 报的 64 个 ERROR 是什么

| 类别 | 数量 | 判定 |
|---|---|---|
| clearance | 41 | **假阳性**。检查器用统一 6mil 在量，板子的实际规则是 `Track↔Track = 0.10199878mm = 4.02mil`（`Safe Spacing / copperThickness1oz` 表第一行）。实测最小 4.50mil > 4.02mil，且远高于嘉立创 3.5mil 工艺下限。原生 DRC 报 0。 |
| silkscreen-flipped | 23 | **真问题但只影响外观**。底层封装属性文本未镜像，会印出反字。这些不是位号，是每个器件旁印的封装名（`C0402` 之类），量产板本就不该印。修法：EDA 里选中器件关闭「封装」属性显示。agent API 改不动。 |

其余 711 条为 WARN，其中大量 `danglingEnds` 是铺铜连通造成的假阳性。
