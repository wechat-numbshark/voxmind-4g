# VoxMind 电源修复：固件改动与少量改线

日期：2026-11-06。接 [31 号调查报告](31_VoxMind电量不准与关机掉电调查_20261106.md)。适用 EVT v9 实板，固件 `1.0.27-power.1` 起。

一句话：固件能做的都做了，而且新旧板子通用。要让关机后电池真正存得住，还需要做**改线 A**：在板上加两个小 MOS 管，给 4G 模组加一个电源开关。

---

## 1. 推荐顺序

1. **先刷新固件**（USB 或 OTA 都行）。这一步必须在改线之前做：旧固件不认识新加的电源开关，改线后模组会一直断电，设备就联不上网了。
2. 做改线 A（必做）。改线 B 顺手做，十分钟。
3. 按第 5 节验证。
4. 改线 C 是安全项，确认电池型号后再做。

---

## 2. 固件改了什么（`1.0.27-power.1`）

| 改动 | 没改线的板子 | 做了改线 A/B 的板子 |
|---|---|---|
| 关机前让触摸芯片进深睡（约 5 µA），不再整晚扫描 | 生效 | 生效 |
| 深睡前钉住悬空的脚：灯的数据线、触摸/屏幕复位、屏幕片选、SD 片选、麦克风时钟、马达，以及 4G 的 TX、DTR | 生效 | 生效 |
| 关机时断开 4G 模组电源（GPIO46） | 无效果，日志会写明“没做改线 A”，仍按旧办法只关射频 | **模组彻底断电** |
| 联网卡死、5 分钟连不上服务器时，先给模组断一次电再重启 | 无效果 | 模组卡死也能恢复，不再需要按 12 秒电源键 |
| **关机掉电实测**：关机前把电量、电压、时间记进 RTC，开机时算出关机期间掉了多少电、折合多少 mA，随心跳上报 | 生效 | 生效 |
| **电量计重置处理**：开机发现电量计刚上过电（电池被放空过），等确认没插电后按当前电压重估一次 | 生效 | 生效，而且直接读 USB 插拔，判断更准 |
| **显示平滑**：放电时只降不升、充电时只升不降，每 2 秒最多变 1%；反方向的变化持续 3 分钟才采信 | 生效 | 生效 |
| **低电量保护**：带载电压低于 3.40 V 持续 1 分钟，屏幕提示“电量耗尽”后自动关机 | 生效，但关机后模组还在耗电 | 生效，关机后电池能一直停在这个电量 |
| 充电状态直读：BQ24074 的 /PGOOD 低电平 = USB 插着 | 读不到，继续用电压推断 | **直读，不再靠猜** |

心跳里新增 `power` 字段：电压 `mv`、电量计速率 `crate`、`usb`（没做改线 B 时为 null）、`gaugeReset`、`modemSwitch`（本次开机断电是否成功过），以及关机后第一次开机才有的 `offDrain`。云端把它写进 `device.boot_diagnostics` 和每 5 分钟一条的 `device.health_diagnostics` 审计记录里，这样也就有了电量曲线。

## 3. 改线 A：给 4G 模组加电源开关（必做）

**为什么要做**：现在模组经 R28（0Ω）直接焊在电池上，什么都关不掉它。关机后电池会一直被放到保护板切断，电量计也跟着清零。

### 3.1 材料

| 位号 | 器件 | 说明 |
|---|---|---|
| QA | **AO3401A** P-MOS，SOT-23（LCSC C15127） | 开关本体。导通电阻约 50 mΩ，4G 发射 2 A 峰值时压降约 0.1 V |
| QB | **AO3400A** N-MOS，SOT-23（LCSC C20917，和板上 Q1 同型号） | 由 GPIO46 驱动，去拉低 QA 的栅极 |
| RA | 100 kΩ 0402/0603 | QA 栅极到源极，平时让开关保持断开 |
| CA | 100 nF 0402/0603 | 和 RA 并联，开通时软启动约 1 ms，避免 470 µF 储能电容瞬间拉垮电池电压 |
| RB | 10 kΩ | QB 漏极到 QA 栅极 |
| RC | 100 kΩ | QB 栅极到 GND。ESP32 没电、深睡、刚上电时开关都保持断开。**GPIO46 是启动选择脚，只能下拉，不能上拉** |
| 线 | 主电流两段（电池→QA→模组）用 AWG26 或更粗的短线；控制线用细漆包线即可 | |

SOT-23 脚位（两颗相同）：1 = G 栅极，2 = S 源极，3 = D 漏极。

### 3.2 接法

```
电池侧 R28 焊盘(VBAT) ──┬───────────── QA.S(2)
                        │                 │
                       RA 100k ∥ CA 100nF │
                        │                 │
                        └──── QA.G(1) ────┘      QA.D(3) ── 模组侧 R28 焊盘(VBAT_MODEM)
                                 │
                               RB 10k
                                 │
                              QB.D(3)
GPIO46（ESP32 模组 16 脚）── QB.G(1) ── RC 100k ── GND
                              QB.S(2) ── GND（C32 负极或任一 GND 焊盘）
```

步骤：

1. 拔掉电池。**拆下 R28**（0Ω，0402）。
2. 分清 R28 的两个焊盘：先接回电池，量到电池电压的那一端是 **VBAT**；另一端接着 C32（470 µF 电解）正极，是 **VBAT_MODEM**。量完再拔掉电池。
3. 把 QA、QB 和三颗电阻、一颗电容做成一个小板，或者用胶带垫底，飞线固定在 C32 旁边。
4. QA 的 S 接 VBAT 焊盘，D 接 VBAT_MODEM 焊盘，这两段线要短、要粗。
5. QB 的 G 飞一根细线到 ESP32-S3-WROOM-1 模组的 **16 脚（IO46）**。网表里这个网络叫 `TP_GPIO46`，板上如果有对应测试点，焊在测试点上更方便。
6. QB 的 S 和 RC 的另一端接 GND。

### 3.3 通电前检查（万用表）

- QA 的 S 和 D 之间不能短路（不接电池时，二极管档只能看到一个体二极管的压降）。
- GPIO46 对地约 100 kΩ（就是 RC）。
- 接上电池、**刷新固件之前**：VBAT_MODEM 应为 0 V。也就是开关默认断开，正确。

## 4. 改线 B：充电检测（推荐，一根线）

把 **R3 的 CHG_PGOOD 端**飞线到 **J8 的 4 脚**（GPIO44，原 UART0 RX；控制台走 USB，没人用它）。R3 另一端是 +3V3，接之前用万用表确认：没插 USB 时 CHG_PGOOD 端也是约 3.3 V，插上 USB 后会变成 0 V，变化的那一端才是对的。

做完后插一次 USB，日志会出现“读到 /PGOOD 低：改线 B 已接”，之后心跳里 `power.usb` 显示 true/false。这个状态存在 NVS 里，只需要识别一次。

---

## 5. 改线 C：电池第三根线（温度保护，可选）

1. 先确认电池第三根线是 **10 kΩ NTC**：常温下量第三根线和黑线（GND）之间，应在 8～12 kΩ。量出来不是这个范围的，不要接。
2. **拆掉 R4**（10 kΩ，TS 脚的固定偏置）。不拆的话 NTC 和 R4 并联约 5 kΩ，充电芯片会以为电池过热，直接停充。
3. 换用 3 针插头接 J1：1 = VBAT，2 = GND，3 = TS。插之前用万用表核对极性，不要凭线色判断。

做完后，电池过冷或过热时充电芯片会自动停充。

（可选，需要显微镜）MAX17048 的 QSTRT（U5 第 6 脚）按数据手册应接地。它的两边分别是 5 脚 ALRT（没用）和 7 脚 SCL，非常容易连锡，没把握就别动。固件这边已经能处理电量计重置。

## 6. 验证（做完改线 A 后按顺序走一遍）

用 USB 接电脑，在串口看日志：

1. **开机**：应先看到 `init 完成`，然后 4G 正常联网，和改线前一样。
2. **关机**：长按录音键，日志应出现 `断开模组电源：STATUS 已掉，模组彻底断电`。
3. **关机电流**：拔掉 USB，万用表 mA 档串在电池正极，关机 2 分钟后读数。预期 **≤ 1.5 mA**（主要是 WS2812 灯和存储芯片的静态电流）。改线前估计在 5～20 mA。
4. **反复开关机 5 次**，每次都要能联上网。如果断电后模组起不来（日志里 `开机超时`），说明模组上电后还需要电源键，而电源键这条线本来就有问题。这时先把 R28 临时焊回去恢复使用，然后告诉我，我再按实际情况调整开机时序。
5. **关机掉电数据**：关机放一夜再开机，日志会出现 `上次关机 X 小时：电量 A% → B%，折合关机电流约 N mA（模组已断电）`。云端也能查到：

```sql
select at, detail->'power'->'offDrain' from vm_audit_log
where action = 'device.boot_diagnostics' order by at desc limit 10;
```

6. **电量曲线**：`device.health_diagnostics` 每 5 分钟一条，`detail->'batteryPct'`、`detail->'power'->'mv'` 就是放电曲线，可以和第 4 步的实测对照。

## 7. 预期效果

| 指标 | 修复前 | 只刷固件 | 刷固件 + 改线 A |
|---|---|---|---|
| 关机电流 | 估计 5～20 mA（模组醒着、触摸在扫描、脚悬空） | 少掉触摸和悬空脚那部分，模组那部分还在 | 约 0.5～1.5 mA |
| 满电关机能放多久 | 约 2～9 天，然后被放空 | 略长 | 约 1～3 个月 |
| 电量显示 | 放空后重置，偏高再“掉得飞快”；平时会跳 | 会重估，不再跳；但还会被放空 | 基本不会再被放空，电量计不再重置 |
| 电池寿命 | 反复深度过放 | 有低电量保护，但关机后仍会被放空 | 低电量保护 + 关机不耗电，不再深度过放 |
| 模组卡死 | 只能重启 ESP32，模组照样卡着 | 同左 | 断电 3 秒彻底复位 |

开机录音时的耗电（约 100 mA，满电大约 8～10 小时）这次没有动。最大的一块是 4G 模组一直醒着：1.0.11 起关掉了模组休眠，因为休眠后叫不醒，又没有办法复位。**有了改线 A，叫不醒就可以直接断电复位**，重新打开模组休眠就有了兜底，预计录音时能省 25～40 mA。这一项要在改线 A 验证通过后单独做、单独测，没有放进这一版。
