## 零、四个会让你烧掉一整天的坑

### 坑 1：MODEM_RXD / MODEM_TXD 的网名是 **MCU 视角**

> **⚠ 2026-08-29 更正。** 本节此前写反了（当成模组视角去翻译），并把错误一路带进了
> `board.h` / `gen_board_h.py` / `drv_modem.c`。已全部改正。
> 按旧版写，4G 串口会完全不通且**没有任何报错**。

实测依据（活原理图直接读模组符号的脚名，两家模组一致）：

```
U3 脚17 = UART0_RXD (ML307C-GC) / MAIN_RXD (Air780E)   ← 模组的输入，模组在这根线上「收」
U3 脚18 = UART0_TXD (ML307C-GC) / MAIN_TXD (Air780E)   → 模组的输出，模组在这根线上「发」

网络 MODEM_TXD  =  U2_9 (ESP32 GPIO16)  ←→  U3_17（模组 RXD）
网络 MODEM_RXD  =  U2_8 (ESP32 GPIO15)  ←→  U3_18（模组 TXD）
```

模组在脚18 上发 ⇒ **GPIO15 必须配成 ESP32 的 RX**；
ESP32 要让模组收到 ⇒ **GPIO16 必须配成 ESP32 的 TX**。

```c
uart_set_pin(UART_NUM_1, PIN_MODEM_TX /*GPIO16*/, PIN_MODEM_RX /*GPIO15*/, ...);
//                        ↑ 网络名叫 MODEM_TXD    ↑ 网络名叫 MODEM_RXD
```

board.h 已按实测对齐，**照着 board.h 写就不会错**。

### 坑 2：PWRKEY 经 Q2 反相，逻辑是反的

```
GPIO17 ──R26── Q2(MMBT3904) 基极
                Q2 发射极 → GND
                Q2 集电极 → MODEM_PWRKEY_N → U3_7 (模组 PWRKEY / PWR_ON/OFF)
```

模组的 PWRKEY 是**低有效**（拉低 ≥1s 开机）。中间隔了个 NPN 三极管，所以：

| ESP32 GPIO17 | Q2 | PWRKEY 电平 | 模组 |
|---|---|---|---|
| **拉高 (1)** | 导通 | **被拉低** | **开机 / 关机触发** |
| 拉低 (0) | 截止 | 浮空（模组内部上拉） | 无动作 |

**开机序列 = GPIO17 置 1，保持 1500ms，再置 0。** 写成拉低会永远开不了机，而且现象是"完全没反应"，很难查。

### 坑 3：MODEM_RESET_N 没有接到 ESP32

`MODEM_RESET_N` 网络上只有 `C37_1` 和 `U3_15`——**只有一个电容，没有任何 GPIO 驱动它。**

**后果**：软件无法硬复位 4G 模组。模组死机时只能靠 PWRKEY 长按（≥12s）强制关机再开机。
**EVT 阶段可接受**，DVT 改板时建议补一根 GPIO 到 RESET，或至少引到测试点。

### 坑 4：IO45 / IO46 是 strapping 脚，现在空着——别接外设

```
TP_GPIO45 → 只连 U2_26，网络上没有第二个器件（悬空）
TP_GPIO46 → 只连 U2_16，网络上没有第二个器件（悬空）
```

悬空是**正确且安全**的（内部下拉生效）。但如果后续要用这两个脚：

- **GPIO45 = VDD_SPI 选压脚。上电时被外部拉高 → flash 供电变 1.8V → 直接启动失败。**
  只能做**输出**，或做输入但必须保证复位瞬间是低电平。
- GPIO46 = ROM 日志开关。拉高只是关掉启动日志，不致命，但会让调试变瞎。

## 二、外设接线细节

### 2.1 双 PDM 麦克风（MIC1 / MIC2，MSM261DDB019）

```
ESP32 GPIO4 ─→ U7(SN74AXC1T45, DIR=GND ⇒ B→A) ─→ MIC_CLK_1V8 ─┬→ MIC1_4
                                                                └→ MIC2_4
MIC1_1 ─┬─ MIC_DATA_1V8 ─→ U8(DIR=+1V8 ⇒ A→B) ─→ GPIO5
MIC2_1 ─┘
```

**两颗麦共用一根 DATA、一根 CLK，靠 L/R 脚分左右声道：**

| | L/R 脚 (pin 2) | 声道 |
|---|---|---|
| MIC1 | GND | **左** |
| MIC2 | +1V8 | **右** |

→ 固件用 **ESP32-S3 的 PDM RX，配成立体声**，一次读到左右两路。
→ 做波束成形/降噪时，两麦的物理间距决定可用频段，需实测板上距离后填进 ESP-SR 配置。

**电平转换方向已核对无误**（SN74AXC1T45：DIR=H → A→B；DIR=L → B→A）：
U7 的 DIR 接地 = 3.3V 侧→1.8V 侧（时钟输出 ✓）；U8 的 DIR 接 1.8V = 1.8V 侧→3.3V 侧（数据输入 ✓）。

### 2.2 存储 U9（CSNP4GCR01-BPW，SD NAND）

**⚠ 引脚号和 MicroSD 不一样，必须按信号名接（原理图已核对，此处仅供固件参考）：**

| U9 脚 | 芯片信号 | 接到 | SPI 角色 |
|---|---|---|---|
| 1 | SDD2 | MICROSD_N6（经 R13 上拉） | SPI 模式下悬空/上拉 |
| 2 | CD/SDD3 | SD_CS | **CS** |
| 3 | SCLK | SD_SCLK | **SCLK** |
| 4 | VSS | GND | |
| 5 | CMD | SD_MOSI | **MOSI** |
| 6 | SDD0 | SD_MISO | **MISO** |
| 7 | SDD1 | MICROSD_N5（经 R12 上拉） | SPI 模式下悬空/上拉 |
| 8 | VCC | +3V3 | |
| 9 | NC | 不接 | |

**DAT1/DAT2 已有上拉电阻（R12/R13）** ✓ 符合 SD 规范要求。

**关键：这颗芯片走 SD 2.0 协议，ESP-IDF 直接用 `sdspi` 驱动即可，和 MicroSD 代码完全一样，零改动。**

### 2.3 电源链

```
USB-C(J2) ─F1─→ VBUS_PROT ─→ U1(BQ24074 充电管理) ─┬→ VBAT ─→ J1(电池)
                                                    └→ VSYS_RAW ─→ U4(TPS63802 升降压) ─→ +3V3
                                                                                            └→ U6(TLV75518) ─→ +1V8
电池电量：U5(MAX17048) 挂 I2C，地址 0x36
```

**两个软件读不到的量（EVT 已知限制）：**

| 量 | 现状 | 固件对策 |
|---|---|---|
| 充电状态 CHG_PGOOD | 只到 R3，**没接 GPIO** | 用 MAX17048 的电压/SOC 上升趋势推断 |
| USB 插入 VBUS | 只到保护器件，**没接 GPIO** | 用 ESP32-S3 原生 USB 外设的总线检测，或同上 |

DVT 改板建议：把 CHG_PGOOD 接一个 GPIO（1 根线的事，省掉一堆推断逻辑）。

### 2.4 人机

| 器件 | 接法 | 极性 |
|---|---|---|
| SW1/SW2/SW3 | 按下接地 | 低有效，**必须开 GPIO 内部上拉** |
| LED1 WS2812C-2020 | VDD=+3V3, DIN=GPIO47, DOUT 未接 | 单颗；用 RMT 或 SPI 驱动 |
| 马达 | GPIO42 ─R24─ Q1(AO3400A NMOS) 栅极；R25 栅极下拉；**D7 续流二极管已加** ✓ | 高有效 |

### 2.5 连接器

| 位号 | 型号 | 脚位 |
|---|---|---|
| **J5** LCD+触摸 | BM12B-GHS-TBT (12P GH1.25) | 1=3V3 2=GND 3=SCLK 4=MOSI 5=CS 6=DC 7=RST 8=BL 9=SDA 10=SCL 11=TP_RST 12=TP_INT |
| **J8** 烧录调试 | BM06B-GHS-TBT (6P GH1.25) | 1=3V3 2=GND 3=TXD0 4=RXD0 5=EN 6=IO0 |
| **J1** 电池 | PH-3AW | 1=VBAT 2=GND 3=NTC(接 BQ24074 的 TS 脚) |
| **J6** 马达 | XY-PH2.0-2P | 1=+3V3 2=MOTOR_N |
| **J7** 天线 | U.FL | 2=射频，两侧 GND |
| **J4** SIM | Micro SIM 6P H1.35 翻盖 | 接 Air780E 的 SIM_VDD/DATA/CLK/RST |

> **J1 是 3 脚电池座**：`1=VBAT 2=GND 3=TS`。
> **买两线电池，J1_3 悬空。** 板上 R4 已经是 10kΩ 接地，即 BQ2407x 数据手册的
> 「禁用温度检测」配置。再挂一颗 10k NTC 会并联成 5kΩ，不再是禁用值，可能被判过温停充。
> 要真正的温度保护：**拆掉 R4** 再用 10k(103AT) NTC 的三线电池。

## 三、待你确认的一件事：触摸屏型号

`J5` 引出了 `TP_INT` / `TP_RST` 和共用的 I2C，**说明这块屏是带电容触摸的**。
但屏幕模组还没定（v3 需求里建议换 2.0"）。定下型号后需要填进 `board.h` 的 `I2C_ADDR_TOUCH_HINT`：

| 常见触控 IC | I2C 地址 | 备注 |
|---|---|---|
| FT6236 / FT6336 | 0x38 | 最常见 |
| GT911 | 0x5D 或 0x14 | 复位时序决定地址 |
| CST816S | 0x15 | 低功耗，常配小圆屏 |

**和 MAX17048(0x36) 都不冲突**，任选其一都能共存在同一条 I2C 上 ✓

选屏时的硬约束：**12 脚 GH1.25 接口 + SPI 显示 + I2C 触摸**，引脚顺序要能对上 J5，否则要做转接板。
