# VoxMind EVT_V1 首板 Bring-up 清单

> **v8 历史清单，不得直接用于 v9 实板。** 其中 Air780E、12P J5、屏幕未定型等信息已经失效。
> v9 请使用 `交付/VoxMind_v9_到货采购装配与开发完全指南_20260830.md`；本文件仅保留作历史排错参考。

**板子焊回来之后，按这个顺序做。不要跳步——每一步都是在为下一步排除变量。**

配套自检固件：`firmware/main/bringup.c`（`main.c` 里 `VOXMIND_MODE_BRINGUP 1`）

---

## 第 0 步：上电之前（不通电，5 分钟）

| 检查 | 做法 | 不做的后果 |
|---|---|---|
| **VBUS/VBAT/3V3/1V8 对地是否短路** | 万用表二极管档量对 GND 阻值，应 > 几百 Ω | 短路直接上电 = 冒烟 |
| **U9 (SD NAND) 方向** | 看 1 脚标记对不对得上丝印 | 反了会烧 |
| **Q2 (MMBT3904) 方向** | SOT-23 三极管，贴反不会烧但模组永远开不了机 | 白查半天 |
| **U7/U8 电平转换片方向** | 两颗 SN74AXC1T45 长得一样，别贴反 | 麦克风没声音 |

**只插 USB-C，不装电池。** 先让最简单的电源链跑起来。

---

## 第 1 步：电源链（10 分钟）

按顺序量，**上一级不对就不要往下查**：

```
USB-C VBUS  → 5V     （量 F1 后面）
VSYS_RAW    → 约 4.4V（BQ24074 输出）
+3V3        → 3.3V   （TPS63802 输出，U4）
+1V8        → 1.8V   （TLV75518 输出，U6）
```

> ⚠ **+1V8 是常开的**，没有软件开关。它没电就是 U6 或它的输入有问题。

---

## 第 2 步：烧录通路（10 分钟）

两条路任选：

- **USB-C 直连**：GPIO19/20 是原生 USB，`idf.py flash` 应该直接认到 USB-Serial-JTAG
- **J8 排针**：`1=3V3 2=GND 3=TXD0 4=RXD0 5=EN 6=IO0`

烧不进去时按这个顺序查：

1. 串口日志有没有输出？没有 → 量 EN 脚，应为高
2. 一直在复位重启 → **量 GPIO45**。它是 VDD_SPI 选压脚，**被拉高会让 flash 供电变 1.8V，直接启动失败**（见真值表坑 4）。板上它是悬空的，如果量到高电平说明有漏电或焊锡搭连
3. 报 PSRAM 错 → `sdkconfig` 里 `CONFIG_SPIRAM_MODE_OCT` 必须为 `y`（N16R8 是八线 PSRAM）

---

## 第 3 步：跑自检固件（5 分钟）

```bash
cd firmware
idf.py build && idf.py -p /dev/cu.usbmodem* flash monitor
```

自检会逐项打印，失败会直接告诉你该查哪里。**逐项对照下表确认：**

| # | 项 | 通过标准 | 失败最可能的原因 |
|---|---|---|---|
| 1 | PSRAM 8MB | 识别到 ≥8MB | sdkconfig 没配八线模式 |
| 2 | MAX17048 (I2C 0x36) | 能读到电压 | U5 贴反 / I2C 没上拉 |
| 3 | 电池电压 3.0~4.3V | 在区间内 | **见下方「电池选型」** |
| 4 | SD NAND 挂载 | 挂载成功 | U9 贴反 / R12,R13 缺失 / SPI 太快 |
| 5 | PDM 初始化 | 无错误 | U7/U8 方向 / +1V8 没电 |
| 6 | 左麦 MIC1 有信号 | 峰值 > 50 | MIC1 焊接 |
| 7 | 右麦 MIC2 有信号 | 峰值 > 50 | MIC2 焊接 / U8 的 DIR 应接 1V8 |
| 8 | 双麦独立 | 两路数值不同 | L/R 脚配置错，或只有一颗麦在工作 |
| 9 | Air780E 开机 | STATUS 拉高 + AT 有回应 | **见下方「模组开不了机」** |

## ⚠ 电池选型

**J1 是 3 脚座：`1=VBAT  2=GND  3=TS(温度检测)`。**

**买两线电池就行，不要买带 NTC 的三线电池。**

原因：板上 `R4` 是 **10kΩ 从 TS 接到 GND**，这正是 TI 数据手册里
「禁用外部温度检测电路」的标准配置（BQ2407x datasheet：
*"To disable the external temperature sense circuitry, connect a 10-kΩ resistor from TS to VSS"*）。

所以：

| 接法 | TS 看到的阻值 | 结果 |
|---|---|---|
| **两线电池，J1_3 悬空** | 10kΩ（只有 R4） | ✅ 正常充电，温度保护关闭 |
| 三线电池，NTC 接到 J1_3 | 10k ∥ 10k = **5kΩ** | ⚠ 不再是禁用值，很可能被判为过温而**停充** |

**如果你确实想要温度保护**（量产建议要），改法是：
**拆掉 R4**，然后用 10kΩ(103AT) NTC 的三线电池。DVT 可以把 R4 改成不贴。

## ⚠ 模组开不了机（第二容易踩的坑）

**PWRKEY 经 Q2(NPN) 反相，逻辑是反的：GPIO17 拉【高】才是触发。**

写成拉低的话，现象是"完全没反应"，没有任何报错。按这个顺序查：

1. 万用表量 GPIO17：固件置 1 时应为 3.3V
2. 量 Q2 集电极（MODEM_PWRKEY_N）：GPIO17 为高时，这里应被拉到接近 0V
3. 都对但还是不开机 → 量 U3 的 42/43 脚（VBAT_MODEM）有没有电
4. **注意 4G 模组开机瞬间电流可达 2A**。只用 USB 供电（无电池）时可能因为掉压起不来——
   **插上电池再试**，这一条经常是真凶

## 第 4 步：人工确认项（自检测不了的）

| 项 | 怎么确认 |
|---|---|
| 振动马达 | 自检会让它短振两下，用手摸 |
| 背光 | 自检最后会点亮，用眼看 |
| WS2812 状态灯 | 需要先补完 `drv_feedback.c` 里的时序（标了 TODO） |
| SIM 卡 | 插卡后自检会打印 `AT+CPIN?` 和 `AT+CSQ` 的结果 |
| 4G 上网 | `AT+CGATT?` 应返回 1；再 `AT+CSQ` 看信号，低于 10 要检查天线 |

---

## 第 5 步：屏幕（要等选型定下来）

屏幕**还没定型**（v3 需求建议换 2.0"）。选屏时的硬约束：

- **12 脚 GH1.25 接口**，脚序必须对得上 J5：
  `1=3V3 2=GND 3=SCLK 4=MOSI 5=CS 6=DC 7=RST 8=BL 9=SDA 10=SCL 11=TP_RST 12=TP_INT`
- SPI 显示 + I2C 电容触摸
- 触控 IC 地址不能是 0x36（那是电量计），常见的 FT6236(0x38) / GT911(0x5D) / CST816S(0x15) 都不冲突

**脚序对不上就要做转接板**，采购前务必拿这张脚位表去比对。

---

## 第 6 步：功耗实测（决定"一直待机"能不能成立）

目标值（v3 需求 §四）：

| 部件 | 目标 |
|---|---|
| ESP32-S3 深睡眠 | ~10 µA |
| Air780E PSM | ~3 µA（标称值，实测通常更高） |
| 整机待机 | 需实测 |

**测法**：串一个电流表在电池正极，跑深睡眠 + 模组 PSM，静置 10 分钟看稳态值。

**PSM 的 TAU 要根据实测调**：TAU 越长越省电，但下行推送延迟越大。
起步 `TAU=1h / Active=30s`，如果发现"有网了马上处理"体验不好，把 TAU 调短，代价是待机变短。
这个权衡没有标准答案，要按你实际的使用频率定。

## 已知的 EVT 硬件限制（记录，DVT 再改）

| # | 限制 | 影响 | DVT 建议 |
|---|---|---|---|
| 1 | `MODEM_RESET_N` 没接 GPIO | 模组死机只能靠 PWRKEY 长按 12 秒 | 补一根 GPIO |
| 2 | `CHG_PGOOD` 没接 GPIO | 软件读不到充电状态，只能靠电量计趋势推断 | 补一根 GPIO（1 根线省一堆逻辑） |
| 3 | USB VBUS 没接 GPIO | 同上，读不到"插没插 USB" | 同上 |
| 4 | 升降压开关节点线宽只有 10~12 mil | 满载 2A 时会偏热 | 引脚处保持窄、出来后加宽到 20~25 mil |
