# VoxMind 明天实板首测：从上电到云端闭环

日期：2026-09-13　适用硬件：`VoxMind_EVT_V1_PCB1_20260830_112615`

## 先记住两件事

- 屏幕与主板使用到货的 **15Pin 硬质 FFC/FPC 排线**；照片里的彩色 15Pin 杜邦母线只适合逐线调试，不作为装机连接线。
- 第一次不要直接烧持续录音版。先烧 bring-up，所有供电、存储和基本外设通过后再烧 cloud-lab。

## 1. 机械与断电检查

1. 完全断电，电池先不接；检查屏幕 15Pin 排线两端金手指朝向和座子锁扣。
2. 用万用表确认主电源对地没有近似短路，再接 USB 限流上电。
3. 4G 天线接好后才让 ML307C-GC 长时间联网；SIM 卡方向按外壳丝印。
4. 电池极性必须先量，J1 的实际针脚以 v9 交付主指南为准。

## 2. 烧首板自检固件

进入目录：

```bash
cd /Volumes/neo/projects/voxmind/firmware/releases/VoxMind_EVT_V1_PCB1_bringup_20260913
ls /dev/cu.*
python3 -m esptool --chip esp32s3 -p /dev/cu.你的串口 -b 460800 \
  --before default_reset --after hard_reset write_flash \
  --flash_mode dio --flash_size 16MB --flash_freq 80m \
  0x0 bootloader.bin 0x8000 partition-table.bin \
  0xf000 ota_data_initial.bin 0x20000 voxmind.bin
python3 -m serial.tools.miniterm /dev/cu.你的串口 115200
```

预期依次看到：PSRAM、电量计/电池、SD NAND、左右麦、4G 模组、马达、屏幕八色色带和 CST816D 触摸坐标。任一供电项异常时先停下，不烧 cloud-lab。

## 4. 验证云端与触摸队列

1. 控制台“最近录音”的块数量持续增加，点播放能听到 WAV 包装后的板端 PCM。
2. 在“没有接麦克风时，也能测试真实 AI 管线”输入一条带“创建”的明确命令；当前生产为 mock，只验证识别、策略和回执，不会误写飞书。
3. 将某一工具策略设成“每次确认”，再发送同类命令；卡片应留在队列。
4. cloud-lab 屏幕顶部短条表示队列数，串口显示队首标题；触摸底部左半区取消、右半区确认。
5. 断开 Wi-Fi 录 1 分钟再恢复：本地序号应继续，恢复后按序出现“云端已持久化”，没有重复块。

## 5. 当前已知边界

- ASR 生产凭据尚未配置，所以“板端说话自动变成文字”暂不工作；本地录音、上传、回放和真实 LLM 文字联调都可测。
- cloud-lab 当前保存 16 kHz/16-bit 单声道 PCM，约 115 MB/小时；用于首轮可靠性验证，不是长续航格式。
- 4G PPP、Opus、OTA、中文卡片字体与 8 小时/50 次断电压力测试仍属于实板迭代项。
- 飞书已实现一键建应用/OAuth 与真实执行器，但生产保持 mock；网页授权和一条人工确认测试通过后再切 live。
