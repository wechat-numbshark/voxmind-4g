## 官方资料

- https://www.waveshare.com/wiki/2inch_Capacitive_Touch_LCD
- https://files.waveshare.com/wiki/2inch-Capacitive-Touch-LCD/2inch_Capacitive_Touch_LCD_Demo_ESP32S3.zip

官方示例 `2inch_Capacitive_Touch_LCD.ino`：ST7789、240×320、背光输出 HIGH；触摸 CST816D 地址 0x15、400kHz。随包 `Arduino_ST7789.cpp/.h` 在 ESP32 上选择 SPI mode 3，包含 B0/B2/B7/BB/C0/C2/C3/C4/C6/D0/E0/E1 初始化；`cst816d.cpp` 复位拉低 200ms、释放后等待 300ms，读寄存器使用 STOP 分隔。

当前移植保留 VoxMind board.h GPIO，不复制官方开发板 GPIO；用 mode 3、10MHz 保守频率、官方寄存器参数、100% 背光、官方触摸复位等待。修复异步 DMA 图像提交后立即复用/释放缓冲的问题，等待传输完成再复用。编译及实板结果需另行确认，不保证这些差异就是黑屏根因。

## 供电及安全

官方 ESP32-S3 示例：屏幕 VCC 留空，3V3 接 3.3V，GND 接地。
本地 `.easyeda/voxmind_v9_mechanical.json`（20260830 存档）：J5 1、2 为 +3V3，3 为 GND。存档不是实测，也不是当前在线 EDA；第 1 脚处理与官方示例不同，仍需核对屏幕电路，不能直接断言安全或根因。

屏幕可通过正确线束由主板供电，不应盲目增加外部电源。断开 USB 和电池才可测通断；红表笔插 V/Ω，黑笔插 COM，不插电流孔。先核对接口引脚，避免探针在细小插座内造成桥接。带电测量只用直流电压档，并在明确安全测试点后进行。
