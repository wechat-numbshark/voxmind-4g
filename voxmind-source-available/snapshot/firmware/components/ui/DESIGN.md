# VoxMind 设备屏幕

2 英寸 240×320 竖屏，LVGL 9，ESP32-S3。和网页控制台（`cloud/web/DESIGN.md`）是同一个世界：
**灰底上插着白纸条，纸条左边的卡槽颜色只表示风险等级。** 设备屏是进程单的随身延伸——划走一条就是签掉一条。

方案来源：`docs/design/device-screen-options.html`，用户选定 A + B 两屏。

## 结构

| 屏 | 内容 | 手势 |
|---|---|---|
| **A 回执流**（默认） | 白色状态带：44px 时钟、电池图标 + 百分比、日期（充电时换成「充电中/已充满」）→ 录音行：红点、「录音中」、走时、9 根电平 → 纸条区（通常 2 张） | 在回执纸条上左右划＝划掉；其他地方左右划＝翻到 B |
| A 有待确认时 | 紧凑状态带（24px 时钟、红点、走时、电量）→ 卡片（风险签、2 行标题、原话、剩余时间）→ 取消 / 确认 | 来卡片时自动翻回 A |
| **B 时刻表** | 大时钟、日期、录音胶囊（红点、走时、电量）→ 今天按时间倒排最多 6 行：时间 / 类型 / 标题 | 待确认那行黄底黄框置顶，点它回 A 去签 |
| 覆盖层 | 开机自检（进度条 + 版本号）、升级进度、关机（白底）；软关机（深底 + 琥珀色耗电提醒） | 挡住触摸 |

纸条区在 y=146..270 之间：卡片高 54px、间隔 8px，描边占用也计入预算，不读取 LVGL 尚未刷新出来的旧高度。底部提示从 y=272 开始。B 屏列表底部限制在 y=300，给页码留空间。

纸条区优先级：电量低（<15% 且没在充）/离线且有待传合并为一张通知 → 执行回执 → 没有回执时「今天」概况。暂停只显示在录音行，电平停止刷新并隐藏，不再额外插入一张重复暂停卡。
「今天」概况在云端统计没拉到时标「本次开机」，只报本机录的时长——不说「今天录了 0 分钟」这种假话。
云端快照之后的本机补时用有效编码采样累计量的差值，不用墙钟；暂停不会继续增长，音频分段不会归零。

划掉回执绑定按下时的不可变 ID；数据刷新会取消未完成手势，不能按旧槽位删除新回执。后台接受删除后才消失，联网后重试同步。确认/取消入队失败时保留卡片并提示重试。

## 字

只有三个字号，都是思源黑体（Noto Sans SC），见 `fonts/gen_fonts.sh`：16 Medium（正文）、24 Bold（标题、按钮）、44 Medium（只含 `0123456789:%.- `，时钟）。
图标只有 LVGL 自带的 Montserrat 14 符号（充电闪电）。

- 字库是 GB2312 一二级 + A1/A3 区 + ASCII。**中点用「・」U+30FB**，「·」U+00B7 和「✓」都不在字库里，会显示成方块。
  云端发给设备的文字经 `cloud/src/device-glyphs.ts` 过滤，改字库要同步重新生成。
- 单行标题一律定高 + `LV_LABEL_LONG_DOT`：LVGL 只有高度固定时才出「…」，否则会折行被切掉。卡片标题定高 70（正好两行 24px）。
- 倒计时写「还剩 N 分钟」，不写 `14:53`——同屏有时钟，会被读成钟点。
- 长提醒有固定标题/正文预算，明确显示省略号，确认入口始终在屏幕内。完整内容仍可去网页查看。

## 性能规矩（界面任务从 46–74% CPU 降到 3% 靠的是这些）

- 只用纯色、圆角、1px 线。不用渐变、阴影、`clip_corner`（纸条的色条缩进 4px 避开圆角，而不是裁剪）。
- 没有常驻动画。录音点是静态红点，「活着」靠电平条（10Hz，只在 A 屏常态可见时画）。
- 文字和颜色没变就不设：`set_text()` / `set_color()` 先比较再写。
- 画布在 PSRAM（内部 RAM 要留给 TLS）。

## 验证

`sh tools/test-host.sh` 做 ASan/UBSan 纯逻辑回归。真实 LVGL/中文字库的桌面检查：

```sh
cmake -S components/ui/tests/host -B build-cloud-current/ui-host
cmake --build build-cloud-current/ui-host -j8
(cd build-cloud-current/ui-host && ./ui-check)
```

输出普通主题/剪纸主题暂停页、长提醒 PPM，覆盖布局边界、刷新取消手势、队列拒绝/接受后的状态。此检查不替代触摸驱动、LCD、DMA 或真机性能测量。

串口命令（设备配好密钥后可用）：`screenshot` 回传真实帧（RGB565，每行一段 base64，前缀 `SHOT:`），
`page a|b` 翻屏，`demo boot|off|sleep|clear` 单独调出开关机画面。界面改动以实拍为准。
