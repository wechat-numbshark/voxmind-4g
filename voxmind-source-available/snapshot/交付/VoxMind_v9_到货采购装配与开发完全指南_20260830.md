## 0. 先看结论

- 当前 PCB 与外壳已经用嘉立创 EDA v9 的完整实板装配 STEP 做过虚拟干涉检查：PCB、屏幕、电池、J6 高度代理与上下壳均无非预期交叠。
- 当前 v9 PCB 不需要为了这套外壳增加安装孔或再改板；外壳通过周边承托、四处 PA12 弹性卡扣和 4 颗 M2 螺钉固定。
- 这次应只做 `5 片 PCB/SMT + 1 套外壳首件`。真实打印、贴片、屏幕、电池、胶带和线材都有公差；收到首件完成本指南的试装和测试后，才能冻结第二批或对外销售。
- 微雪 2inch Capacitive Touch LCD 不是“裸屏直接压进去”：需要先接匹配的 15P 线，再用 0.5 mm 框形胶固定黑边，并保留软排线回弯空间。
- 3D 打印订单只包含打印件，不自动包含屏幕、电池、天线、螺钉、胶、声学网、脚垫或 SIM 卡。

## 2. 到货后先不要装壳

### 2.0 四条立即停止条件

- 电池极性不明、鼓包、破损、异常发热，或无法确认保护板/放电能力。
- 任一电源轨持续近似短路，首次上电瞬间满限流、冒烟、异味或器件快速发热。
- U3、U9、U10/U11、J4、J8 的面别、旋转或 1 脚方向与 v9 资料不一致。
- 屏线、同轴线或电池线只能靠强压合盖，或者屏幕、PCB、电池存在硬顶。

出现以上任一情况都不要“继续试试看”，先断电、拍照并记录板号。

### 2.1 建立追溯记录

1. 拍外箱、标签、PCB 工单号、SMT 批次、3D 打印订单号和每种物料包装。
2. 给 5 块板编号 `V9-01`～`V9-05`；首块只使用 `V9-01`。
3. 记录屏幕、电池、天线的供应商、型号、批次和实测尺寸。
4. 所有测试结果都按板号记录；不能用“一块能开机”代替 5 块板的来料结论。

### 2.2 PCB/SMT 目检

在放大镜下逐块检查：

- 板边无崩裂、明显翘曲、分层和毛刺；USB-C、J1、J5、J7、J8、Nano-SIM 座无歪斜或机械损伤。
- U3（ML307C）、U9（SD NAND）、U10/U11（电平转换）、J4（Nano-SIM）、J8（调试口）的面别、旋转和 1 脚方向与嘉立创生产预览一致。
- U10/U11 与 C40～C43 位于底面且均已贴装；U3 脚 100 必须保持 NC。
- C38/C39 是 DNP 预留位，空着是正常的；不要自行补 1.0 pF。
- 没有锡珠、连锡、虚焊、立碑、器件裂纹或模组屏蔽罩凹陷。
- J1 是全板唯一插件件；若来料未焊或运输受力，先处理它，不能靠外壳顶住。

若发现极性件/连接器方向疑似错误，先停下并拍正反面高清照片，不要上电“试试看”。

### 2.3 3D 打印件目检

- 应收到：上壳、底壳、OK/BACK/REC 三键、透明导光柱、TPU 防撞套，共 7 个零件。
- 上下壳和三键应各自为单一实体，无裂纹、粉末堵孔、明显翘曲或缺角。
- 底壳被平台提示“易变形结构”属于首件工艺风险，不等于已判废；把底壳放在玻璃平面上检查四角是否同时落地，并用塞尺记录最大翘曲。
- 导光柱必须透明、无断裂；若订单仍报告反向三角面，不应付款/生产，应先使用修复后的模型。
- TPU 套无分层和撕裂，拉伸后能回弹。
- 用卡尺记录外壳外廓、PCB 承托宽高、屏幕腔、按键孔、USB-C/SIM 开口和螺钉孔，不要先打磨以掩盖问题。

## 3. 裸板第一次上电

### 3.1 断电检查

1. 不接屏幕、不接电池、不插 SIM、不接天线。
2. 万用表电阻档测 USB VBUS 对 GND、VBAT 对 GND、3V3 对 GND、1V8 对 GND。
3. 电容会让读数跳变，不能用一个固定欧姆阈值判断；重点是没有持续近似短路/蜂鸣，并比较 5 块板读数是否同一量级。
4. 单块明显偏低或持续蜂鸣，立即隔离该板，不要上电。

### 3.2 限流上电

1. 优先只插 USB-C。若用台式电源，先设 5.0 V、100 mA 限流；确认没有异常后再逐级提高到满足板载启动需求。
2. 第一次上电手指不要压住模组；观察是否瞬间满限流、冒烟、异味或局部快速发热。任一异常立即断电。
3. 先不要启动 4G 模组。ML307C 的峰值电流较大，完整蜂窝测试应在确认电源正常并接入合格电池后进行。
4. 测试并记录 5V/VBUS、3V3、1V8、VBAT/系统电源和 `MODEM_VDD_EXT`。ML307C 开机后 `MODEM_VDD_EXT` 正常应约 1.8 V，绝不能与板上 1V8 或 3V3 短接。

## 4. 烧录与首板自检

### 4.1 环境

当前仓库固件是 ESP-IDF v5.2+ 的首板骨架，不是可直接销售的完整产品固件。它能帮助验证基础硬件，但屏幕完整显示/触摸、联网业务、量产测试、OTA 和产品 UI 仍需继续开发。

```bash
cd /Volumes/neo/projects/voxmind/firmware
. "$IDF_PATH/export.sh"
idf.py set-target esp32s3
idf.py build
idf.py -p /dev/cu.usbmodemXXXX flash monitor
```

- 优先用 USB-C 原生 USB-Serial-JTAG 烧录（GPIO19/20）。
- 若 USB 无法进入下载模式，再用 J8：`1=3V3, 2=GND, 3=TXD0, 4=RXD0, 5=EN, 6=IO0`；以 v9 板上 1 脚标记为准。
- 烧录失败时：按住 BOOT，再短按 EN/复位，开始下载后松开 BOOT。
- 不要在串口适配器和目标板之间同时互相供电；至少保证共地，并明确由哪一侧供电。

### 4.2 自检顺序

按以下顺序测试，前一项失败先修，不要跳着把全部附件装上：

1. ESP32-S3 启动、16 MB Flash、8 MB Octal PSRAM。
2. MAX17048，I2C 地址 0x36；接入电池后电压应在约 3.0～4.3 V。
3. U9 SD NAND 挂载、读写、掉电后重读。
4. 双 PDM 麦克风左右声道；同一声源下记录增益差，整机目标差值不大于 3 dB。
5. 三个实体按键、WS2812 指示灯和振动马达。
6. 屏幕背光、SPI 显示、I2C 电容触摸、四角和边缘触摸。
7. 最后测试 ML307C：PWRKEY、STATUS、UART、SIM、注册网络和数据上传。

ML307C 关键点：

- v9 已由 U10/U11 完成 ML307C 1.8 V 与 ESP32 3.3 V 的双向电平转换；不要飞线旁路。
- ESP32 视角 `GPIO16=TX → 模组 RXD`，`GPIO15=RX ← 模组 TXD`。
- PWRKEY 经 Q2 反相：ESP32 GPIO17 拉高会把模组 PWRKEY 拉低。
- Air780E 的厂商私有联网指令不能直接照搬；基础 `AT`、SIM 和信号查询可先验证，联网层按 ML307C 手册实现。

## 5. 屏幕、电池和天线的台外试装

### 5.1 屏幕

1. 断电。
2. 对照 v9 J5 的 1 脚标记和屏幕线标记，确认 15P 连接线方向；有锁扣先打开锁扣，插到底后再锁。
3. 线自然做 U 形回弯，最小弯曲半径不小于 3 mm；不得在连接器根部折死。
4. 通电测试白/黑/红/绿/蓝纯色、背光、触摸四角和滑动；通过后再粘屏。

### 5.2 电池

1. 先测电池自身电压和插头极性；把实测正负极写在标签上。
2. 对照 J1：pin1=VBAT、pin2=GND、pin3=TS 留空。不要依据红黑线颜色盲插。
3. 先关机再插电池；确认不发热，再做充电、断 USB 续航和电量计测试。
4. 电池鼓包、刺破、异常发热或线根损伤立即停用并按锂电池规范隔离处理。

### 5.3 SIM 与 LTE 天线

1. 断电插入 Nano-SIM，确认缺角方向；不要热插拔。
2. U.FL 公母座正上方对准，垂直轻压到位；禁止斜压、旋转硬拧或拉同轴线拔插。
3. 未接 LTE 天线时不要长时间让 ML307C 发射。
4. 裸板完成 `AT`、SIM 识别、信号查询、注册网络和连续上传 30 分钟后，再装壳比较信号。

## 6. 正式装壳顺序

### 6.1 预装上壳

1. 清理 PA12 粉末；M2 孔只手动试牙，不高速攻入。
2. 透明导光柱从壳内插入，PCB 端轻磨平，装配后与 LED 保留约 0.2～0.5 mm 间隙。
3. 两个麦克风孔内侧贴 6 mm 低声阻声学网，不能堵住孔。
4. 三颗按键从上壳内侧向外穿入：REC 有中心凹点，BACK 有偏心缺口；逐颗按 20 次，必须自由回弹。
5. 先干装屏幕确认窗口居中、四周无硬顶；再贴黑 PET 遮光片和 0.5 mm 框形胶。
6. 只压屏幕黑边，禁止压显示区、排线和触摸玻璃；屏幕玻璃应低于保护沿约 1.2 mm。
7. 先接 15P 线再粘屏，给排线保留 U 形弯折腔。

### 6.2 预装底壳

1. PCB 斜放到底壳周边承托，依次压过四个卡扣；只压板边，禁止压 C32、U3、SIM 座和连接器。
2. 检查 USB-C 与左侧开口、Nano-SIM 与右侧开口是否同心，插拔不刮壳。
3. 电池托盘底贴 0.5 mm Poron，放入电池，再贴 1.0 mm 上缓冲。
4. 电池不得与 C32、焊点、螺钉柱、PCB 边或壳体硬接触；轻摇无窜动，但也不能被过度压缩。
5. 核对极性后接 J1，电池线沿右上方三个导线环走，不跨 SIM 座和螺钉柱。

### 6.3 天线、合盖与防撞套

1. LTE FPC 天线贴在上壳右内侧约 10 × 40 mm 的塑料平面，保持平直；不要贴在屏幕金属背板上或折过锐角。
2. 同轴从 J7 沿内部通道走，留少量应力释放，不进入上下壳缝。
3. 合盖前逐一确认：屏线、电池线、同轴线、USB-C、SIM、三键和导光柱都未被夹住或顶住。
4. 上下壳先靠定位舌自然贴合；有明显阻力就打开查线，禁止靠螺钉强行拉拢。
5. 4 颗 M2 × 16 对角分两轮手拧。首件从约 0.10 N·m 起，以不滑牙、不白化、壳缝均匀为准。
6. 套 TPU 防撞圈，确认 USB-C、SIM、麦克风孔和按键均未被遮挡；最后贴脚垫和铭牌。

## 7. 合盖后的完整验收

### 7.1 每台必测

- [ ] USB-C 插拔和充电正常，插头不被壳体顶住。
- [ ] Nano-SIM 可正常插拔，卡座不松动。
- [ ] OK/BACK/REC 各按 100 次，无卡键、连击或手感漂移。
- [ ] 屏幕无亮斑、压痕和漏光；触摸四角、边缘、滑动正常。
- [ ] 导光均匀；马达振动无异响。
- [ ] 左右麦克风都能录音，灵敏度差不大于 3 dB，声学网不堵音。
- [ ] 电池不窜动，线材无夹伤；充电、电量显示、断 USB 运行正常。
- [ ] 4G 注册和数据上传正常；装壳前后信号差异有记录。
- [ ] 边充电边连续 4G 上传 30 分钟，无重启、掉网和异常气味。
- [ ] 室温工程目标：常触表面低于 48 °C，电池表面低于 45 °C。超过即停止销售冻结并复核热设计。
- [ ] 深睡、按键唤醒、低电关机和再次充电恢复正常。

### 7.2 首件结构冻结测试

- [ ] USB-C 插拔 200 次、SIM 插拔 30 次、TPU 拆装 20 次。
- [ ] 三键各 1000 次，无断裂、卡滞或保持翻边脱出。
- [ ] 1.0 m 跌落：6 面、8 角各一次；壳不自开、电池不移位、屏幕不破、功能正常。
- [ ] 屏幕正面与背面分别承受 5 kg 静载 1 分钟后无压伤、PCB 无永久弯曲、触摸正常。
- [ ] 0～45 °C 工作检查和充电检查；若计划更宽温度范围，另做专业验证。
- [ ] 裸板与装壳后的 LTE、Wi-Fi/BLE RSSI/吞吐做同地点同姿态对比。

任何一项失败，都先修结构参数或装配工艺，再下第二批；不要用打磨、加厚泡棉或大力锁螺钉掩盖系统性偏差。

## 8. 常见故障定位

| 现象 | 先检查 |
|---|---|
| USB 插上完全无反应 | 数据线、VBUS 对 GND 是否短路、F1/USB-C 焊接、3V3 是否建立 |
| 只能进下载模式 | BOOT 键/IO0 是否被压住，J8 线序，固件分区和 Flash 模式 |
| 屏幕只亮背光无画面 | 当前固件是否已移植该屏驱动、15P 线方向、J5 锁扣、SPI CS/DC/RST |
| 触摸无反应 | I2C 0x36 是否被重复初始化、触摸地址/驱动、TP_INT/TP_RST、线序 |
| 电池不充电 | 电池极性、J1 pin1/pin2、R4/TS 偏置、充电芯片、USB 输入能力 |
| 电量百分比异常 | MAX17048 0x36、初次校准、连接器压降、电池型号参数 |
| ML307C 没有 `AT` | 电池/模组供电、PWRKEY 反相、STATUS、U10/U11 供电与方向、UART 交叉关系 |
| SIM 不识别 | 必须断电，Nano-SIM 缺角方向、J4 焊接、卡是否开通，不要沿用旧 Micro-SIM 资料 |
| 装壳后信号变差 | LTE 天线是否贴到屏幕金属背板、同轴是否夹伤、天线折死、PCB 天线净空被遮挡 |
| 按键卡住 | 帽体方向、PA12 粉末、孔隙、上下壳错位、螺钉扭矩过大；不要给按键加油 |
| 麦克风声音闷/左右差大 | 声学网是否堵孔、孔位对齐、装配压迫、PDM 左右通道和 U7/U8 |

## 9. 从首件到可销售版本

当前是可销售目标下的 EVT 工程样机基线，不等于已经完成法规和量产验证。完成以下项目后再冻结 DVT：

1. 把实测 PCB、C32、开关柄、USB-C、屏幕、电池和天线尺寸写回 `结构设计_v1_20260830/voxmind_enclosure.py`。
2. 重新生成 STEP/STL，运行 `verify_enclosure.py`，保存报告、照片、扭矩和问题清单。
3. 修复首件问题后再下 5 套；第二批仍需抽检装配与跌落。
4. 完成完整屏幕/触摸驱动、ML307C 联网层、录音业务、异常恢复、OTA、量产测试和序列号追溯。
5. 正式销售前让合规机构确认目标地区适用的 CCC、SRRC、进网、EMC、安全、锂电运输和标签/说明书要求。结构 CAD 通过不能代替整机合规。
