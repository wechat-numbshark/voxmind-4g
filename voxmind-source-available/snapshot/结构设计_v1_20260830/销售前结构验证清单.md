# VoxMind 销售前结构验证清单

判定：所有“阻断项”必须 PASS；任一 FAIL 都不能把当前外壳称为销售冻结版。

## A. 来料与可追溯性（阻断）

- [ ] PCB/SMT 批次、外壳批次、屏幕批次、电池批次可追溯。
- [ ] 电池包带保护板，额定持续放电 ≥2 A；极性 100% 来料检验。
- [ ] 中国境内销售使用的便携式锂电池/电池组具有有效 CCC 标识和证书，符合 GB 31241-2022。
- [ ] 外壳材料、染色和后处理有订单记录；量产转注塑前重新做阻燃/材料评估，不能把 PA12 样件结论直接沿用到注塑料。

## B. 尺寸与装配（阻断）

- [ ] PCB 不弯曲即可压入；四个卡扣完整咬合，拆卸工具可解除卡扣。
- [ ] 合盖后缝隙均匀，目标 `≤0.5 mm`，无错台、翘角、夹线。
- [ ] M2 螺钉对角锁紧无滑牙/白化；重复拆装 10 次仍可保持。
- [ ] 屏幕黑边被支撑，显示区不受压；玻璃低于保护沿 `0.6~1.2 mm`。
- [ ] 用至少 3 种常见 USB-C 插头验证可完全插入，无壳体顶住插头肩部。
- [ ] Nano-SIM 可插拔并能明确识别方向；卡片不会掉入壳内。
- [ ] 电池任何位置不与焊点、C32、屏幕、螺钉柱硬接触；轻摇无窜动。
- [ ] 同轴、屏线和电池线均有应力释放，不进入壳缝或螺钉区。

## C. 人机与声学（阻断）

- [ ] OK/BACK/REC 不看设备也能凭触感区分；REC 凹点、BACK 缺口清楚。
- [ ] 每键自由回弹 1000 次，无连击、卡死或壳体常压；装壳前后触发力变化不超过 30%。
- [ ] 触屏四边和四角均能点击，屏幕无彩虹纹/压痕。
- [ ] 两麦克风装壳前后 1 kHz 灵敏度变化分别记录，左右差目标 `≤3 dB`。
- [ ] 录音、手握、桌放三种状态无明显风噪啸叫；声学网没有被胶堵塞。
- [ ] 状态灯在室内可辨、夜间不刺眼，导光柱不直接硬压 LED。

## D. RF、热与续航（阻断）

- [ ] LTE 天线装壳后完成驻波/总辐射或至少同批对比测试；不能只看“能联网”。
- [ ] Wi-Fi/BLE 与裸板相比没有不可接受的 RSSI/吞吐下降；屏幕金属背板不覆盖 ESP32 天线净空。
- [ ] 最差工况：边充电边连续 4G 上传 30 分钟；记录壳体、ML307C 区域、电池表面温度。
- [ ] 工程目标：正常室温下常触表面 `<48 °C`、电池表面 `<45 °C`；超出则停止销售冻结并做热设计复核。
- [ ] 低电量发射不重启，USB 插拔不重启，屏幕满亮与振动同时动作不掉电。

## E. 可靠性（阻断）

- [ ] 1.0 m 跌落：6 面、8 角各一次；壳不自行打开、电池不移位、屏幕不破、功能正常。
- [ ] 5 kg 静压 1 分钟施加于正面/背面，屏幕不受力变色，PCB 不永久弯曲。
- [ ] 40 °C 高温运行 8 h、0 °C 低温启动（工程筛查条件）后按键/卡扣/胶带正常。
- [ ] USB-C 插拔 200 次工程筛查后壳口无明显磨损、接口无松动。
- [ ] SIM 插拔 30 次后卡座和壳口正常。
- [ ] TPU 套拆装 20 次无撕裂，且不遮挡 USB/SIM/麦克风。

## F. 标识与售后

- [ ] 背面铭牌至少包含型号、额定输入、制造商/责任主体、批次或序列号和必要认证标识。
- [ ] 说明书写明电池、充电、温度、SIM、无线与回收注意事项。
- [ ] 维修作业指导书明确开壳顺序、螺钉规格、屏幕胶更换和电池处置。
- [ ] 每台整机有功能测试记录：充电、屏幕、触摸、三键、双麦、4G、Wi-Fi/BLE、存储、振动、LED。

## G. 认证边界

结构 CAD 通过不等于整机合规。产品正式销售前，按销售地区和整机归类让合规机构确认适用的 CCC/SRRC/进网、EMC、安全和电池运输要求。特别是锂电池：国家认监委 2023 年第 10 号公告明确，便携式电子产品用锂离子电池和电池组自 2024-08-01 起纳入 CCC 准入；适用标准包括 GB 31241-2022。
